### How does the code work?
The sequential commands branch has the code from PID and EncoderDrive, which means you can call both of those commands in the sequential commands code. You can call the EncoderDrive command to make the robot move forward or backward, and you can call the PID command to make it turn. The code that we wrote for PID and EncoderDrive was kind of like making our own Scratch code blocks, and now in the sequential commands code we can call those commands just like we can drag out move and turn blocks in Scratch.
